# Wallet API
Учебный проект, симулирующий работу электронного кошелька. Главная ценность проекта — демонстрация строгого контроля за целостностью данных. В системе полностью исключены ситуации, когда из-за конкурентных запросов баланс пользователя «уходит в минус», или когда деньги списываются у одного клиента, но не доходят до другого.

## 🚀 Ключевые особенности и архитектура безопасности

- **ACID Транзакции**: Все операции перевода, пополнения и списания изолированы на уровне базы данных.
- **Защита от Race Conditions**: Реализована блокировка строк (Pessimistic Locking / SELECT FOR UPDATE) для предотвращения конкурентного изменения баланса.
- **Идемпотентность API**: Повторные сетевые запросы на перевод средств защищены уникальными ключами идемпотентности, что исключает дублирование списаний.
- **Docker**: Контейнеризированное окружение, готовое к мультиплатформенной сборке.
- **Автоматические миграции**: База данных разворачивается автоматически с помощью Alembic.

## 🛠 Технологический стек

- Язык разработки: Python 3.11+
- Фреймворк: FastAPI / SQLAlchemy
- База данных: PostgreSQL
- Кэш и очереди задач: Redis / Celery / RabbitMQ
- Миграции БД: Alembic
- Контейнеризация: Docker, Docker Compose

## 🏗 Быстрый старт


### 1. Клонирование репозитория

```bash
git clone https://github.com/max-dv800/wallet-api.git
cd wallet-api
```

### 2. Настройка окружения

Создайте файл .env в корневом каталоге и заполните его по шаблону:
```
#Redis база
REDIS_HOST=
REDIS_PORT=
REDIS_DB=
PENDING_TTL=
COMPLETED_TTL=

#Локальная база данных (Postgresql)
DB_HOST=
DB_USER=
DB_PASS=
DB_PORT=
DB_NAME=

#Брокер сообщений (RabbitMQ)
RABBIT_HOST=
RABBIT_USER=
RABBIT_PASS=
RABBIT_PORT=

#API - ключи, ttl токенов
SECRET_KEY=
MAX_ACCESS_AGE=
MAX_REFRESH_AGE=

#Переменные транзакций
MAX_SINGLE_DEPOSIT=
MAX_DAILY_DEPOSIT=
MAX_TRANSFER_AMOUNT=
EXCHANGE_LIMIT_RUB=
EXCHANGE_LIMIT_USD_EUR=

```
### 3. Запуск через Docker Compose

Для сборки и запуска всех сервисов выполните:
docker-compose up --build

Контейнер автоматически применит миграции базы данных через Alembic перед запуском веб-сервера.

## 🔌 API Эндпоинты
